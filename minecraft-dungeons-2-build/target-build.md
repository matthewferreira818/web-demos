# Target build: Sculker's Bane soul build

The build planned in chat on 2026-10-04, before the current gear was known. It is theorycraft from datamined numbers (Metabot, game build 1.1.1.0) and Maxroll's early build notes. Nothing here has been tested in-game.

## How it works

- Sculker's Bane hits are soul damage and its combo is a single 0.48 s attack, so "final hit" enchantments such as Soul Blast fire on every swing.
- Artifacts spend souls; Twisted Tooth and the soul-capacity effects keep the bar full.
- Enchantments that trigger on artifact use (Artifact Amplifier, Health Synergy, Gravity Pulse) fire constantly with short-cooldown artifacts.
